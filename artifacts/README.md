# Local verification output

Run the `test:kit:browser`, `test:experiment:browser` and `benchmark:experiment` scripts to regenerate reports, screenshots and measurements. See `docs/solid-three-experiment.md` for the methodology. Per-agent task reports and raw benchmark results stay local under `artifacts/`.

This README is tracked; generated files are ignored and checked by CI. Removing them from the current Git tree preserves local copies and does not erase earlier commits. CI debug artifacts have bounded retention and are separate from Git source.
